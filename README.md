Amazon Sale Data Analyst Dashboard | Power BI
Project Overview
This project uses Power BI to analyze Amazon sales data, focusing on sales performance, geographical distribution, product categories, promotions, order status, and fulfilment.

Data Modeling
FactSales: Main sales transaction data, including order details, sales amount, quantity, and transaction information.
DimArea: Area information and area classification.
DimDate: Date attributes for time-based sales analysis.
DimProduct: Product information and product categories.
DimPromotion: Promotion details and discount-related information.
DimShipping :Shipping methods and delivery-related information.

Dashboard Pages & Analysis
Page 1 -- Sales KPI Overview -- Overall sales performance and key business indicators
Page 2 -- Area & Sale Channel -- Area distribution and sales channel performance
Page 3 -- Order & Style -- Order trends and product category analysis
Page 4 -- Promotion & AOV -- Promotion performance and average order value analysis
Page 5 -- Order & Funnel Stage -- Order distribution and purchasing funnel analysis
